## 💻 Sobre o Projeto

O **EPIE** é um middleware de alta performance desenvolvido para processar grandes volumes de eventos de forma assíncrona. O sistema utiliza mensageria para garantir a durabilidade dos dados e integra modelos de **Inteligência Artificial (LLMs)** para análise de criticidade e classificação automática em tempo real. É um projeto focado em demonstrar padrões de resiliência, escalabilidade e o uso prático de IA em backends robustos.

## 📚 Pré-requisitos de Habilidades e Níveis de Conhecimento

Antes de ingressar neste conteúdo, é necessário possuir conhecimento prévio nas seguintes áreas:

- **Desenvolvimento Backend (Node.js ou C#)** | Avançado
- **Bancos de Dados Relacionais e NoSQL** | Avançado
- **Arquitetura de Microserviços** | Intermediário
- **Lógica de Programação e Clean Code** | Especialista

## 🛠️ Habilidades e Sub-habilidades que vamos aprender neste conteúdo

- **Sistemas Distribuídos**
  - Implementação de Mensageria (Kafka/RabbitMQ)
  - Padrões de Resiliência (Circuit Breaker, Outbox Pattern)
- **IA Generativa no Backend**
  - Integração com APIs de LLM (OpenAI/Gemini)
  - Orquestração com LangChain
- **Observabilidade e Infraestrutura**
  - Monitoramento de métricas e logs estruturados
  - Estratégias de Cache Global com Redis

## 🎯 Objetivos e Resultados Esperados

Após a conclusão do curso/projeto, os estudantes estarão aptos a:

- Projetar arquiteturas backend capazes de suportar picos súbitos de tráfego sem perda de dados.
- Integrar fluxos de inteligência artificial em pipelines de dados assíncronos.
- Decidir criticamente entre diferentes tecnologias de mensageria e persistência baseando-se em trade-offs técnicos.
- Construir soluções que unam visão de negócio (custo-benefício) com excelência técnica de nível Tech Lead.
